## 🎨 设计系统速查（《美食的俘虏》意境转化）

### 配色

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 · 焰火红 | `#E8482A` | 主按钮 / 激活 Tab / 关键数据 / 匹配度 |
| 辅色 · 熟金黄 | `#F0A73E` | 强调 CTA / 收藏星标 / 对话框 / 能量条 |
| 成功 · 食材绿 | `#2FA37E` | 已收藏 / 完成勾选 / 健康营养 |
| 背景 · 奶油暖白 | `#FFF7EC` | 页面底色（烘焙暖感） |
| 描边 · 墨褐 | `#241A12` | 粗描边 / 硬阴影 / 标题 |
| 辅助 | 深咖 `#4A2E1D` 正文 / 米金 `#F6E3C3` 标签底 / 灰 `#8A6F5C` 弱化 |

### 字体
- 标题/强调：Noto Sans SC **900** 紧字距
- 品牌/拟声词：`ZCOOL KuaiLe`（站酷快乐体，漫画感）
- 正文：苹方 / 微软雅黑 / Noto Sans SC 400–700

### 漫画风设计语言
1. **粗描边**：所有组件 `2.5px solid #241A12` 黑色描边
2. **硬阴影**：`4px 4px 0 #241A12` 无模糊偏移阴影（漫画分格感）
3. **半调网点**：登录/引导页背景用 `radial-gradient` 网点纹理
4. **速度线**：挑战卡 / 引导页用斜向重复条纹
5. **对话框标签**：`star-burst` 金字标签 + `bubble` 气泡卡片
6. **拟声词**："生成魔法菜谱""食材猎人推荐""捕获成功"等漫画口吻文案
7. **微动效**：按钮按压缩放、语音麦克风脉冲（CSS 实现，纯原型演示）

### 核心组件（全部内联 CSS，各文件保持一致）
- 底部 TabBar（百科/厨房/发现/我的）· 顶部 Nav（返回/标题/操作）
- 主按钮 `btn-red/gold/green/white` · 标签 `chip` · 分段 `seg`
- 匹配度能量条 `energy`（火焰渐变）· 星级收藏 `i-star` · 点赞 `i-heart`
- 瀑布流 `wf` · 列表 `menu` · 统计 `stats` · 滑块 `slider` · 勾选 `check-item`
- 相机取景框 `cam-view` · 语音波形 `wave` · 周计划条 `week-strip`
- 营养条 `nutri-row` · 投票条 `vote-bar` · 进化树 `evo-tree`
