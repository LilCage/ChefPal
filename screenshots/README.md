## 截图规范

- **来源**：微信开发者工具模拟器右上角「截图」按钮，或真机预览截屏后导出。
- **尺寸**：建议 **750×1200**（模拟器 375×667 @2x），宽高比固定为 5:8，README 里按 280px 宽显示。
- **格式**：`.png`。
- **命名**：小写 kebab-case（如 `home-qa.png`），语义 = 页面功能名。
- 想要展示**交互效果**（流式打字机 / 滚动跟随）时，可改用录屏转 GIF（`.gif`），README 同样支持。
