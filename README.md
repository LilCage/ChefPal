# 🍳 ChefPal · 你的口袋 AI 厨师

> **从食材到餐桌，全程智能陪伴。**
> 让每一个不会做饭的人都能轻松下厨，让每一个会做饭的人都能吃得更好、更健康。

---

## 📌 一句话定位

不做"菜谱大全"（下厨房已做）、不做"社区平台"（豆果已做）——做 **动态生成式烹饪伴侣**：
基于**你的食材 + 你的目标**，实时生成专属方案。

> **核心差异化：生成式，而非检索式。** 不是从菜谱库里搜，而是为你的冰箱实时"变"出菜。

---

## ✨ 功能亮点

| 模块 | 说明 |
|------|------|
| 🏠 **AI 烹饪百科**（首页） | 文本问答 + AI 联网搜索 + 结构化回答（核心秘诀 / 食材 / 步骤 / 避坑指南），问答历史与收藏 |
| 🍳 **食材魔方**（厨房） | 输入食材（文字/拍照/语音）→ AI 生成 TOP3 菜谱，标注匹配度 / 时间 / 难度 / 缺什么调料 |
| 🧭 **发现 · 社区广场** | 作品发布、瀑布流浏览、点赞、话题标签、带小程序码分享卡片 |
| 👤 **我的厨房** | 微信一键登录、口味设置（忌口/辣度/咸淡/技能）、收藏管理、精美分享卡片 |

**扩展方向（P1–P3）**：拍照识食材 · 语音输入 · 3/7 天膳食规划 + 营养分析 · 购物清单 · 黑暗料理拯救 · 家庭口味投票 · 时令食材日历 · 多智能体协作（营养师+大厨+采购）…

## 🛠 技术栈（方案设计文档 v1.0）

| 层 | 选型 |
|----|------|
| 小程序前端 | **Taro 4 + React + TypeScript**（跨端复用） |
| UI 组件库 | **NutUI-React**（京东官方） |
| 后端 | **FastAPI + LangChain / LangGraph（Python）** |
| AI 大模型 | **阿里云百炼 DeepSeek**（v4-flash 为主 / v4-pro 兜底，原生联网搜索 + 结构化输出） |
| 数据库 | **PostgreSQL**（JSONB 存结构化菜谱/问答，预留 pgvector 做 RAG） |
| 认证 | 微信 code2Session + JWT |
| 部署 | Docker（本地 PG + 后端）→ 上线后置 |

> 完整技术选型对比见 [docs/方案设计文档.md](docs/方案设计文档.md)。

## 🚀 MVP 核心闭环（第一目标）

```
微信登录 → 厨房输食材 → AI 生成 TOP3 菜谱 → 详情 / 收藏
         → 首页提问厨艺问题 → AI 联网搜索 + 结构化回答 → 历史 / 收藏
```

**验收标准**：输入"西红柿、鸡蛋、面条"→ 生成 3 道菜（含匹配度 + 步骤），可收藏，核心差异化闭环跑通。
